# Agent or automation? The three tests

Run anything sold to you as an "AI agent" through these.

**Test 1 · Adapt.** The page changed, the reply was angry, the data came back empty. Does it cope, notice, and retry differently? A workflow breaks. An agent re-plans.

**Test 2 · Plan.** Can you give it a goal instead of a step? Does it pick the tools, decide the order, and know when it's done?

**Test 3 · Improve.** Does it keep a record of what worked, start the next run from that record, and tell you why it changed?

## Score it
- **Three yes:** agent.
- **One or two:** assisted automation. A fine thing.
- **Zero:** automation. Ship it and call it that.

## What to build in each case
- **Automation:** n8n, Make, Zapier. Cheapest and most predictable. Most jobs want this.
- **Assisted automation:** a workflow with one model step and a human check. Proposals, summaries, triage.
- **Agent:** only where the world changes between runs and being wrong is cheap enough to let it re-plan. Research, enrichment, qualification. Never invoices.
